Установка

Как открыть второе окно

  1. Откройте приложение

    Скачайте архив для Windows 10 или 11 x64, распакуйте его и запустите TwoWindowsInOne.exe.

  2. Активируйте приложение

    Пройдите CAPTCHA, скопируйте ключ с этой страницы и активируйте его в приложении.

  3. Выберите программу

    Выберите поддерживаемую программу или её файл .exe и нажмите «Открыть второй профиль».

Поддерживаются Chrome, Edge, Brave, Chromium, Vivaldi, Firefox, VS Code, VS Code Insiders и VSCodium. Если окно нельзя встроить в рабочую область, второй профиль откроется отдельно. Данные профиля сохраняются между запусками.
