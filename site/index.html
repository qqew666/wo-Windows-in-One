Установка

Как открыть второе окно

  1. Откройте приложение

    Скачайте архив для Windows 10 или 11 x64, распакуйте его и запустите TwoWindowsInOne.exe.

  2. Активируйте приложение

    Пройдите CAPTCHA, скопируйте ключ с этой страницы и активируйте его в приложении.

  3. Выберите программу

    Выберите открытую программу или файл .exe и нажмите «Открыть программу». Для установщика или программы, которая блокирует второе окно, выберите Windows Sandbox.

Браузеры и редакторы с поддержкой отдельных профилей сохраняют данные второго экземпляра между запусками. Windows Sandbox требует поддерживаемой редакции Windows и очищает гостевую систему при закрытии.
