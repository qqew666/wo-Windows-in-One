Запуск и обновление

Как открыть второе окно

Установите приложение

Запустите установщик, откройте Two Windows in One и активируйте короткий ключ. Для первой активации нужен интернет.

Выберите программу

Поддерживаемые браузеры и редакторы запускаются с новым профилем. Другие программы можно открыть под второй учётной записью Windows или в Windows Sandbox.

Обновляйтесь из лаунчера

Кнопка «Обновления» проверяет релизы на GitHub и загружает новый установщик. Если загрузка не удалась, релиз можно открыть в браузере. Перед установкой лаунчер освобождает встроенное окно.

Windows Sandbox требует аппаратной виртуализации и поддерживаемой редакции Windows. Программы с драйверами или запретом виртуальных машин могут отклонить запуск.
