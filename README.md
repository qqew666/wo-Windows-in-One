# Two Windows in One

**Разработчик:** [qqew666](https://github.com/qqew666)

Приложение для Windows x64 на Rust. Оно запускает поддерживаемую программу с отдельным рабочим профилем. У второго экземпляра свои настройки, история, расширения и данные входа. Его окно можно встроить в рабочую область Two Windows in One, если Windows и сама программа допускают встраивание.

[Скачать Windows x64](https://github.com/qqew666/wo-Windows-in-One/releases/latest) · [Сайт и ключ доступа](https://two-windows-in-one-key-api.sillypetunia8.chatgpt.site/)

## Как запустить

1. Скачайте и распакуйте архив и откройте `TwoWindowsInOne.exe`.
2. Пройдите CAPTCHA на сайте, скопируйте ключ и активируйте его. В полночь по Москве начинает действовать новый ключ.
3. Выберите поддерживаемую программу из открытых окон или укажите её файл `.exe`.
4. Нажмите **Открыть второй профиль**. Если встраивание недоступно, программа откроет отдельное окно со вторым профилем. Кнопка **Отсоединить окно** возвращает встроенное окно на рабочий стол.

Поддерживаются Chrome, Edge, Brave, Chromium, Vivaldi, Firefox, Visual Studio Code, VS Code Insiders и VSCodium. Обычный профиль программы продолжает работать. Профили второго экземпляра хранятся в `%LOCALAPPDATA%\TwoWindowsInOne\Profiles` и используются повторно при запуске того же исполняемого файла.

Нужна Windows 10 или 11 x64. Администраторские права для обычного запуска не требуются. Программа использует собственные параметры профиля выбранного приложения. Доступ к общим файлам и сетевым сервисам определяется правами текущего пользователя. Если оба профиля входят в один облачный аккаунт, сервис может синхронизировать данные между ними.

## Сборка

Установите стабильный Rust и средства сборки Visual Studio с поддержкой C++. Затем из корня репозитория выполните:

```powershell
cargo test --locked --manifest-path app/Cargo.toml
cargo build --locked --release --manifest-path app/Cargo.toml
```

Готовый файл появится в `app/target/release/TwoWindowsInOne.exe`. GitHub Actions проверяет запуск и отсоединение тестового окна из отдельного процесса и публикует архив при отправке тега версии.

## Сайт

`site/` содержит статическую часть сайта. Адрес API задаётся в `site/settings.js`. GitHub Pages можно подключить через **Settings → Pages → Source → GitHub Actions**.

`backend/` содержит сервер CAPTCHA и подписанных ключей. `npm ci && npm run build` собирает Worker в `dist/server/index.js`. Для самостоятельного размещения задайте `TWI_SITE_ORIGIN`, `TWI_CAPTCHA_SECRET` и `TWI_SIGNING_PRIVATE_PEM`. CAPTCHA использует 32 случайных байта в Base64. У закрытого ключа RSA 2048 в формате PKCS#8 должна быть открытая часть из `app/license-public.pem`. Закрытые ключи хранятся в секретах среды.
